# A real execution, with deliberately transparent provenance

This is a **controlled synthetic recording**: Python programs were actually run,
their source and captured output rendered into screens, and narration synthesized
from the scripts in [ground-truth.json](ground-truth.json). It is not an uploaded
user lecture and is not a general ASR accuracy benchmark.

- [Read the transcript and frames on GitHub](index.md)
- [Download/open the standalone HTML](index.html)
- [Download/open the audio and image review queue](review.html)
- [PDF](index.pdf), [JSON](transcript.json), [SRT](transcript.srt), [WebVTT](transcript.vtt)
- [Original recording](source.mp4)

The output was generated by Whisper large-v3, converted from verified official
weights to MLX float16, served from a Mac and called from a Linux development
container. Original ASR errors, including “traciback” and “Na”, remain visible.
The proposed terminology correction is **deferred**, because the demonstration
reviewer inspected screen images but did not claim to inspect audio. Coverage is
two of five speech segments for images and zero for audio; other segments remain
unreviewed. Listen to the excerpts to make your own decision.

Two actual screen transitions occur at approximately 5.234 and 9.281 seconds.
Sampling every 0.5 seconds found candidates at 5.5 and 9.5 seconds. This shows
bounded observation intervals, not frame-accurate semantic event detection.
Three additional frames were extracted on demand around the first transition.
The demo uses a tile threshold of 0.03 for small code-screen changes; the default
threshold is more conservative and can miss such changes.

Reproduce the source with `scripts/make_demo.py` (macOS `say`, or three supplied
audio files on another platform). With a connected ASR server:

```sh
python scripts/make_demo.py --output work/demo-source
please-transcribe run work/demo-source/source.mp4 --work work/demo-session \
  --language en --audit --tile-threshold 0.03 --image-interval 3 \
  --formats md,html,pdf,json,srt,vtt
please-transcribe inspect frames --work work/demo-session --start 5 --end 6 \
  --interval 0.4 --max-frames 5
please-transcribe review focus --work work/demo-session
```

Install the CPU extra for the optional Silero audit, the PDF extra and Chromium
for PDF generation, and fonts with Korean glyphs for the demo's final screen.
ASR output can vary with engine versions and decoding. The saved review report
is an example of an image-based proposal; do not manufacture an audio-verified
approval to make a reproduction match this example.

## Transcription configuration

| Field | Published demo |
| --- | --- |
| Source | Controlled synthetic video, 13.74625 seconds; synthesized English narration over actual Python execution screens. |
| Client/backend | Linux client calling the authenticated remote ASR API; exported `backend=remote`, `server_backend=mlx`. |
| ASR model | OpenAI Whisper large-v3; exported compatible model label `mlx-community/whisper-large-v3-mlx`. |
| Weight source | Official OpenAI large-v3 checkpoint, SHA-256 verified, converted locally to MLX weights. |
| Computation | Native MLX worker, FP16 weights/decoding. |
| Task/language | `task=transcribe`, `language_requested=en`, `language=en`, `multilingual=false`. |
| Audio | Mono 16 kHz PCM16 WAV; normalized float32 input to ASR. |
| Timing | Engine segment and word timestamps; five original ASR segments preserved. |
| VAD | No separate baseline prefilter; optional Silero coverage audit performed afterward. |
| Visual sampling | 0.5-second sampling, 3-second periodic images, tile threshold 0.03; three additional dense frames. |
| Review | Separate image-based proposal, deferred decision; image coverage 2/5 segments, audio coverage 0/5. |

See [transcript.json](transcript.json) for saved transcript metadata and
[the transcription specification](../../docs/TRANSCRIPTION.md) for the checkpoint
hash and decoding behavior. Full library versions and effective decoder settings
were not embedded in this demo's exported transcript; the specification's inspected
library defaults should not be treated as a version manifest for that earlier run.
